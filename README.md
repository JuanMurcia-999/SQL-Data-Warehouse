# Proyecto de Data Warehouse y Analítica

Este proyecto demuestra una solución integral de almacenamiento de datos y analítica, desde la construcción de un data warehouse hasta la generación de insights accionables. Diseñado como un proyecto de portafolio, destaca las mejores prácticas de la industria en ingeniería de datos y analítica.

## Requisitos del Proyecto

### Construcción del Data Warehouse (Ingeniería de Datos)

Desarrolla un data warehouse moderno utilizando SQL para consolidar datos de ventas, habilitando reportes analíticos e informes para la toma de decisiones informada.

- **Fuentes de Datos**: Importa datos de dos sistemas fuente (ERP y CRM) proporcionados como archivos CSV.
- **Calidad de Datos**: Limpia y resuelve problemas de calidad de datos en un modelo de datos único, amigable para el usuario y diseñado para analítica. 
- **Linaje de Datos**: Proporciona la documentación más clara del modelo de datos que no soporte a los stakeholders de negocio y equipos.
